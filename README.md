📌 Project Overview

This project performs an Exploratory Data Analysis (EDA) on a tourism dataset using Python.
The analysis explores tourist demographics, destinations, travel behaviour, accommodation preferences, expenses, satisfaction, booking behaviour, group size, and repeat visitation.
The objective is to identify meaningful patterns and generate useful business insights from tourism-related data.

🎯 Project Objectives
The main objectives of this project are:

Understand the demographic profile of tourists.
Identify popular countries, destinations, purposes, seasons, and travel modes.
Analyse tourist spending and major expense categories.
Study hotel preferences, ratings, and satisfaction.
Analyse seasonal and monthly tourism patterns.
Evaluate tourist satisfaction.
Understand online versus offline booking behaviour.
Analyse repeat visitors and compare them with non-repeat visitors.
Identify cities with stronger repeat-visitor behaviour.
Generate business insights and recommendations.
